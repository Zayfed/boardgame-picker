# Во что сыграть? 🎲

Telegram-бот подбирает настольные игры по числу игроков, времени партии и возрасту младшего участника. По пожеланию пользователя локальная модель проверяет основную тему подходящих игр; бот показывает совпадение с цитатой и ссылкой на источник.

В каталоге **300 карточек Тесеры**, собранных 24–25.11.2026 через BeautifulSoup. Парсер — [boardgames/collect.py](boardgames/collect.py), рабочие данные — [data/games.json](data/games.json). Сайт, домен и входящий порт для Telegram не нужны: бот использует long polling.

## Запуск

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/). Проверено на Python 3.12.13.

```bash
git clone https://github.com/Zayfed/boardgame-picker.git
cd boardgame-picker
uv sync --frozen --python 3.12
cp .env.example .env
```

Создайте бота командой `/newbot` у [@BotFather](https://t.me/BotFather) и заполните `TELEGRAM_BOT_TOKEN` в `.env`. Файл исключён из Git.

Для ИИ установите [Ollama](https://ollama.com/download), запустите `ollama serve` и в другом терминале скачайте модель:

```bash
ollama pull qwen3.5:4b
uv run --env-file .env python -m boardgames.bot
```

Обычная подборка работает без Ollama. При ошибке модели бот объясняет сбой и показывает обычные карточки. Для модели нужно около 4 ГБ диска; она проверена на Mac mini с 16 ГБ RAM.

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Обязательный токен бота |
| `OLLAMA_URL` | Адрес Ollama; по умолчанию `http://127.0.0.1:11434` |
| `OLLAMA_MODEL` | По умолчанию `qwen3.5:4b` |
| `OLLAMA_TIMEOUT` | Время ожидания модели, по умолчанию 180 секунд |
| `GAMES_DATA` | Необязательный путь к JSON; по умолчанию `data/games.json` |

На одном токене запускайте один экземпляр бота.

## Как пользоваться

Откройте [@boardgame_picker_bot](https://t.me/boardgame_picker_bot) или собственного бота. `/find` запускает четыре шага: число игроков → минуты → возраст → пожелание или кнопка «Подобрать без ИИ».

Пример: **6 игроков / 180 минут / 18 лет → «Нравятся птицы»**. Проверенный тематический результат — Tweeeet: 2–6 игроков, 30 минут. «Ещё три игры» пропускает уже показанные карточки. `/cancel` отменяет подборку, `/data` показывает источник и ограничения, `/help` — команды.

Бот предназначен для личных чатов. Диалоги хранятся в памяти до перезапуска; параметры пользователей изолированы. Во время ожидания ИИ можно начать новую подборку через `/find`.

## Данные и ИИ

Сборщик проверяет `robots.txt`, загружает зафиксированные страницы с паузой не менее секунды и извлекает поля из HTML. Снимки сохраняются в `data/html/`; при ошибке прежний JSON не заменяется частичной выгрузкой.

Обновить данные: `uv run python -m boardgames.collect`. Продолжить прерванный сбор с сохранёнными карточками: добавить `--resume`; повторить обработку без сети: `--offline`. После обновления JSON перезапустите бота.

URL и границы выборки: [sources.json](data/sources.json). В записях сохранены название, диапазоны игроков и времени, минимальный возраст, теги, описание, URL и дата сбора. Контрольные суммы HTML и замечания: [quality_report.json](data/quality_report.json). API Тесеры использовался только для поиска URL.

`selection.py` строго проверяет состав, время и возраст, затем ищет формы слов пожелания. `ai.py` передаёт в Ollama до восьми описаний по одному. Модель определяет основную тему и соответствие `direct`, `partial` или `none`; принимается первый `direct`. ID и цитату код берёт из исходных данных.

Каталог неполный; время не включает изучение правил. Неизвестный возраст или верхняя граница времени исключают игру из подборки. Поиск слов и модель могут ошибаться на синонимах, отрицаниях и сложных пожеланиях.
